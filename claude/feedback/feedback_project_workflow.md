---
name: project workflow
description: apply when starting or continuing any feature — scope first, code→tests→docs per module, commit before next
type: feedback
---

**Always**
- Confirm scope before starting — ask "which module/feature?" never assume
- Order within each module: code → tests → docs; never implement modules in parallel
- Commit after each complete module (code + tests + docs) before touching the next — see [[Git workflow]]
- Pause after each module; do not propose the next until user confirms
- One concern per response — no unrelated changes
